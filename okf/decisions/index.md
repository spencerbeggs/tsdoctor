# Decision

* [@tsdoctor/manifest sits below @tsdoctor/bundle](manifest-below-bundle.md) - Split the tsdoctor.json schema out of the bundle package so a writer can depend on encode/decode without the bundle's fetch, cache and discovery stack.
* [@tsdoctor/vfs sits below the registry and the model](vfs-below-registry-and-model.md) - Extract VirtualPackage and TsEnvironment into a dependency-light substrate so the registry and the model share it without depending on each other.
* [A linker is a scope — no mutable current-scope holder](linker-is-a-scope.md) - CrossLinker and ShikiCrossLinker are immutable per-API values, not module-level state a build swaps in and out.
* [A persisted Twoslash result cache is the render-phase performance fix](persisted-twoslash-result-cache.md) - Measurement showed nearly all render-phase code-block cost is Twoslash type-checking concentrated in example blocks, so a persisted, XDG-shared result cache — not per-scope environments — is the performance work.
* [A route collision fails the build, never a synthetic suffix](route-collisions-fail-the-build.md) - Two distinct items resolving to the same lowercased route stop the build; there is no auto-disambiguation.
* [A working VitePress alpha gates every core package's 1.0](vitepress-alpha-gates-1-0.md) - Core @tsdoctor/\* packages stay pre-1.0 until platforms/vitepress proves the core/adapter boundary as a second live consumer; rspress-plugin-api-extractor ships 1.0.0 on that same core.
* [Consolidate into one monorepo](consolidate-into-one-monorepo.md) - Move the type registry, the model library and the RSPress plugin into one monorepo under packages/ and platforms/.
* [Content hashing over mtimes](content-hashing-over-mtimes.md) - The snapshot system compares canonical content hashes, not filesystem mtimes, to decide whether a generated page changed.
* [Core packages, thin adapters](core-adapter-boundary.md) - Frame-neutral logic lives in packages/; each platforms/\* adapter is thin and owns only what a static-site framework forces it to own.
* [Deprecate the model's Render module in favour of @tsdoctor/pages](deprecate-model-render.md) - Mark Render.tree / Render.item / Render.docs @deprecated in packages/model, pointing consumers at renderMarkdown in @tsdoctor/pages, with deletion planned a minor after the deprecation ships.
* [Doc generation runs inside RSPress's config() hook](generate-docs-in-config-hook.md) - The RSPress adapter runs the whole doc generation program from config() rather than beforeBuild, because RSPress scans routes before beforeBuild runs.
* [Effect v4 only](effect-v4-only.md) - The whole monorepo runs on Effect v4 exclusively, pinned through the catalog:effect pnpm catalog, with no v3-shaped code anywhere.
* [Emit the runtime bundleless, per file](bundleless-per-file-runtime.md) - The React runtime is transpiled 1:1 per component rather than bundled, so import.meta.env.SSG\_MD resolves per site.
* [Extract the page IR only once two adapters exist](page-ir-from-two-consumers.md) - @tsdoctor/pages was lifted from the RSPress generators with the VitePress adapter as its second live consumer, validated by a byte-identity gate rather than designed up front.
* [Head tags are built in the generate stage](head-tags-built-in-generate-stage.md) - Head tags are assembled before the frontmatter hash is taken, not in the later write stage, so a head-tag change is visible to change detection.
* [Import the namespace root, never the leaf](import-namespace-root-not-leaf.md) - Generated import type statements for a dotted reference (Schema.Struct) import the namespace root, because the reconstructed declaration body keeps the qualified form.
* [MDX pages serialize each block node separately, joins owned by the emitter](per-node-mdx-serialization.md) - emitMdxBody serializes each block's mdast node as its own one-node Root and places the separators itself, because the kit's MDX-presence escaping is tree-wide.
* [One TypeScript environment per distinct resolved compiler config](per-scope-typescript-environments.md) - Each documented API type-checks under its own resolved compiler options, deduplicated by a fingerprint of the encoded config, so one API's tsconfig no longer wins for every API on a multi-API site.
* [One anchor algorithm, never a second spelling](single-anchor-algorithm.md) - Routes.sanitizeId is the single spelling for every member anchor and cross-link key; anchors are computed once and carried as data.
* [One layer-construction call produces both ManagedRuntimes](two-managed-runtimes.md) - makeAppLayers returns { app, emitter } from a single call so metrics.layer and the BuildEnv references are shared by reference; the emitter stack stays synchronously buildable for the sync-island bridge.
* [One seam decides every head tag, adapters only render](single-headtags-seam.md) - @tsdoctor/seo's headTags(input) is the single source of truth for which head-element tags a page gets; adapters render a HeadTag into their framework's shape and never compose their own.
* [Page IR blocks are Schema.Class variants, not Data.TaggedEnum](blocks-are-schema-classes.md) - The page IR's block vocabulary is modeled as Schema.Class variants tagged on kind and unioned with Schema.Union, matching the mdast shape the IR is built alongside.
* [Post-process llms.txt rather than generate it](llms-post-process-not-generate.md) - The RSPress adapter rewrites @rspress/plugin-llms' own output instead of generating llms.txt from scratch.
* [The VitePress adapter alpha is markdown-only, no Vue components](vitepress-markdown-only-alpha.md) - platforms/vitepress renders every page as plain markdown over native @shikijs/vitepress-twoslash instead of shipping a Vue component layer, keeping the alpha scoped to proving the core seams.
* [The build event bus fans out synchronously, in-process](synchronous-event-bus.md) - EventBus.emit fans out inline to every sink so build-end summaries and metrics read exact counts, and one sync-island bridge module reaches it from outside any Effect fiber.
* [The canonical site URL is derived, never configured](site-url-is-derived-not-configured.md) - There is no siteUrl plugin option; deriveSiteUrl joins RSPress's own siteOrigin and base.
* [The type and Twoslash caches degrade; the snapshot store fails](caches-degrade-snapshot-store-fails.md) - TwoslashCacheService and TypeRegistryService degrade to a cache miss on failure; SnapshotService.layer stays fatal with StoreError | StoreMigrationError, because a silently regenerated snapshot corrupts the timestamps a crawler reads as authoritative.
